# คู่มือผู้ใช้ — ระบบจองห้องประชุม TNN

คู่มือฉบับย่อสำหรับพนักงานทั่วไป ใช้เวลาอ่านประมาณ 5 นาที

---

## 1. เข้าสู่ระบบครั้งแรก

1. เปิดเว็บที่ผู้ดูแลระบบแจ้งไว้ เช่น `https://meeting.example.com`
2. ถ้าได้รับอีเมลคำเชิญ ให้กดลิงก์ในอีเมลเพื่อ **ตั้งรหัสผ่านของตัวเอง**
   (ลิงก์มีอายุ 7 วัน)
3. ถ้าองค์กรเปิดให้สมัครเอง ให้กด **สร้างบัญชี** กรอกอีเมลองค์กร
   แล้วกดลิงก์ยืนยันในอีเมล (ลิงก์มีอายุ 24 ชั่วโมง)

**รหัสผ่านต้องยาวอย่างน้อย 10 ตัวอักษร และมีทั้งตัวอักษรและตัวเลข**

เข้าสู่ระบบครั้งแรกจะเห็นคำแนะนำการใช้งาน 5 ขั้น กด **ข้าม** ได้ตลอด
และเปิดดูใหม่ได้จากหน้า **ช่วยเหลือ**

**ลืมรหัสผ่าน:** กด "ลืมรหัสผ่าน" ที่หน้าเข้าสู่ระบบ ระบบส่งลิงก์ให้ทางอีเมล (อายุ 60 นาที)

> ถ้าใส่รหัสผ่านผิดหลายครั้ง ระบบจะล็อกชั่วคราวเพื่อความปลอดภัย
> รอประมาณ 15 นาทีแล้วลองใหม่ หรือใช้ "ลืมรหัสผ่าน"

## 2. หน้าปฏิทิน — หน้าหลักที่ใช้บ่อยที่สุด

แถบด้านบนมีทุกอย่างที่ต้องใช้

| ส่วน | ใช้ทำอะไร |
|---|---|
| `‹` `วันนี้` `›` | เลื่อนวัน/สัปดาห์/เดือน และกลับมาวันนี้ |
| ช่องวันที่ | กระโดดไปวันที่ต้องการ |
| เลือกห้องประชุม | เลือกห้องเดียว หรือเลือก "ทุกห้อง" เพื่อเทียบหลายห้อง |
| ช่องค้นหา | ค้นหาห้อง ชื่อผู้จอง หรือช่วงเวลาว่าง |
| ปุ่ม `วัน` `สัปดาห์` `เดือน` | สลับมุมมอง (ห้องและวันที่ที่เลือกไว้จะคงเดิม) |
| ปุ่มสีส้ม **จองห้องประชุม** | เปิดฟอร์มจอง |

### สามมุมมองใช้ต่างกันอย่างไร

| มุมมอง | เหมาะกับ | จุดสังเกต |
|---|---|---|
| **วัน** | ดูรายละเอียดและจองงานวันนี้ | มีเส้นแดงบอกเวลาปัจจุบัน และเลื่อนไปใกล้เวลาจริงให้อัตโนมัติ |
| **สัปดาห์** | วางแผนล่วงหน้าทั้งสัปดาห์ | วันนี้ถูกไฮไลต์ รายการที่เวลาทับกันจะแบ่งคอลัมน์ให้เห็นครบ |
| **เดือน** | ดูภาพรวมว่าช่วงไหนว่าง | จุดสีบอก 4 ระดับ กดวันที่แล้วเปิดมุมมองรายวันของวันนั้น |

**ความหมายของจุดสีในมุมมองเดือน**

| สัญลักษณ์ | ความหมาย |
|---|---|
| ○ ว่าง | ยังไม่มีการจอง |
| ◔ มีจองบางช่วง | จองไปบางส่วน ยังมีเวลาว่างเหลือเยอะ |
| ◕ ใกล้เต็ม | เหลือเวลาว่างไม่มาก |
| ● เต็ม | แทบไม่มีเวลาว่างเหลือ |

## 3. จองห้องประชุม

### วิธีที่ 1 — แตะช่วงเวลาว่างในปฏิทิน (เร็วที่สุด)

1. เลือกห้องและวันที่
2. แตะช่องเวลาว่างที่ต้องการ → ฟอร์มจะเปิดขึ้นพร้อมใส่ห้อง วันที่ และเวลาให้แล้ว
3. กรอกหัวข้อประชุม
4. กด **ยืนยันการจอง**

### วิธีที่ 2 — กดปุ่มจองห้องประชุม

กดปุ่มสีส้มมุมขวา แล้วเลือกห้อง วันที่ และเวลาเอง

### ช่องต่าง ๆ ในฟอร์ม

| ช่อง | ต้องกรอกไหม | คำอธิบาย |
|---|---|---|
| หัวข้อประชุม | **ต้องกรอก** | ชื่อที่คนอื่นจะเห็นในปฏิทิน |
| ห้องประชุม / วันที่ / เวลาเริ่ม | **ต้องกรอก** | ระบบใส่ให้แล้วถ้าแตะจากปฏิทิน |
| ระยะเวลา | – | เลือกจากรายการ ระบบคำนวณเวลาสิ้นสุดให้ |
| จำนวนผู้เข้าร่วม | **ต้องกรอก** | ต้องไม่เกินความจุห้อง |
| ความเป็นส่วนตัว | – | ดูตารางด้านล่าง |
| ผู้เข้าร่วม | – | ใส่อีเมล คั่นด้วยจุลภาค — เพื่อนร่วมงานจะได้รับแจ้งเตือนด้วย |
| อุปกรณ์และบริการ | – | เลือกที่ต้องใช้ ถ้าห้องไม่มีจะถูกบันทึกเป็นคำขอบริการเสริม |
| วัตถุประสงค์ / หมายเหตุ | – | ข้อมูลเพิ่มเติม |
| การจองซ้ำ | – | จองหลายครั้งในครั้งเดียว |

### ความเป็นส่วนตัว — เลือกให้เหมาะกับเนื้อหาประชุม

| ตัวเลือก | คนอื่นในองค์กรเห็นอะไร |
|---|---|
| **เปิดเผยในองค์กร** | เห็นหัวข้อและชื่อผู้จอง (ค่าปริยาย) |
| **แสดงเฉพาะว่าไม่ว่าง** | เห็นแค่ว่าช่วงนี้มีคนใช้ ไม่เห็นหัวข้อและชื่อ |
| **ส่วนตัว** | ไม่เห็นรายการนี้เลย — เฉพาะคุณ ผู้เข้าร่วม และผู้ดูแลห้องที่เห็น |

### การจองซ้ำ

ติ๊ก "จองซ้ำหลายครั้ง" แล้วเลือกความถี่ (ทุกวัน / ทุกสัปดาห์ / ทุกเดือน)
และระบุวันสิ้นสุดหรือจำนวนครั้ง

> ถ้าบางครั้งชนกับการจองของคนอื่น ระบบจะ **ข้ามครั้งนั้นแล้วจองครั้งที่เหลือให้** และแจ้งว่าข้ามไปกี่ครั้ง
> จะได้ไม่ต้องเริ่มใหม่ทั้งชุด

### หลังกดยืนยันจะเกิดอะไร

| กรณี | ผลที่ได้ |
|---|---|
| ห้องยืนยันอัตโนมัติ | ขึ้น **ยืนยันแล้ว** ทันที และเห็นในปฏิทินเลย |
| ห้องที่ต้องขออนุมัติ | ขึ้น **รออนุมัติ** และผู้อนุมัติได้รับแจ้งเตือนทันที |

ทั้งสองกรณีคุณจะได้รับอีเมลยืนยัน (และ LINE ถ้าเชื่อมบัญชีไว้)
พร้อมไฟล์ปฏิทิน `.ics` ที่เพิ่มลงปฏิทินส่วนตัวได้

## 4. ถ้าจองไม่ได้ — ความหมายของข้อความที่เจอ

| ข้อความ | หมายความว่า | ทำอย่างไร |
|---|---|---|
| ช่วงเวลานี้ถูกจองไปแล้ว | มีคนจองตัดหน้า (ระบบบอกว่าชนกับรายการใด) | เลือกเวลาอื่น ห้องอื่น หรือกด "เข้าคิวรอห้องว่าง" |
| เวลาที่เลือกอยู่นอกเวลาทำการของห้อง | นอกช่วงเปิดของห้องนั้น | เลือกเวลาในช่วงที่ระบุในข้อความ |
| ห้องปิดให้บริการในวันนี้ | ห้องนั้นไม่เปิดวันนั้น (เช่น เสาร์-อาทิตย์) | เลือกวันทำการ หรือเลือกห้องอื่น |
| จำนวนผู้เข้าร่วมเกินความจุห้อง | คนเยอะกว่าที่ห้องรับได้ | ลดจำนวน หรือเลือกห้องใหญ่กว่า |
| ระยะเวลาจองต้องไม่เกิน ... นาที | เกินเพดานของห้องนั้น | แบ่งเป็นสองช่วง หรือติดต่อผู้ดูแลห้อง |
| ไม่สามารถจองเวลาย้อนหลังได้ | เวลาที่เลือกผ่านไปแล้ว | เลือกเวลาในอนาคต |
| เวลาต้องเป็นช่วงละ ... นาที | ห้องนั้นให้จองเป็นช่วงละ 15/30/60 นาที | เลือกเวลาจากรายการที่ระบบให้ |
| ห้องปิดให้บริการช่วงเวลานี้: ... | ห้องปิดปรับปรุง | เลือกห้องอื่นหรือเวลาอื่น |
| ยกเลิกได้ก่อนเวลาประชุมอย่างน้อย ... นาที | ใกล้เวลาประชุมเกินกว่าจะยกเลิกเองได้ | ติดต่อผู้ดูแลห้อง |
| มีผู้อื่นแก้ไขการจองนี้ไปแล้ว | มีคนแก้รายการเดียวกันพร้อมกัน | โหลดหน้าใหม่แล้วแก้อีกครั้ง |

## 5. ค้นหา

พิมพ์ในช่องค้นหาได้เลย ระบบเข้าใจภาษาไทยแบบผสม

| พิมพ์ว่า | ระบบจะหาให้ |
|---|---|
| `ห้องประชุมใหญ่` | ห้องที่ชื่อตรงกัน พร้อมบอกว่าว่างตอนนี้หรือว่างเมื่อไร |
| `12 คน` | ห้องที่จุได้ 12 คนขึ้นไป |
| `พรุ่งนี้ 13:00 ถึง 15:00` | ห้องที่ว่างจริงในช่วงนั้น |
| `พรุ่งนี้ 13:00 ถึง 15:00 12 คน ทีวี` | ห้องว่างที่จุ 12 คนและมีทีวี |
| `ปิยะ` หรือ `piya@example.com` | การจองของคนนั้น (เท่าที่คุณมีสิทธิ์เห็น) |
| `บ่าย 2` | เวลา 14:00 |
| `20/9` หรือ `20/9/2569` | วันที่ 20 กันยายน |

กด **ตัวกรองเพิ่มเติม** เพื่อระบุอาคาร ชั้น ความจุ หรืออุปกรณ์แบบละเอียด
เงื่อนไขที่ใช้จะแสดงเป็นป้ายเล็ก ๆ กดกากบาทเพื่อลบทีละเงื่อนไข หรือกด **ล้างทั้งหมด**

## 6. แก้ไข ยกเลิก และเช็กอิน

### ดูการจองของตัวเอง

เมนู **การจองของฉัน** — แยกเป็น "การจองที่กำลังมาถึง" และ "ประวัติการจอง"
(รวมรายการที่คุณถูกเชิญเข้าร่วมด้วย)

### แก้ไข / ยกเลิก

เปิดรายการที่ต้องการ แล้วกด **ยกเลิกการจอง**
ระบบจะถามยืนยันและให้ระบุเหตุผล (ไม่บังคับ) แล้วแจ้งผู้เข้าร่วมทุกคนให้อัตโนมัติ

ถ้าเป็นการจองซ้ำ จะเลือกได้ว่า **ครั้งนี้เท่านั้น** หรือ **ทั้งชุด**
(ทั้งชุดหมายถึงครั้งที่ยังไม่ถึงเท่านั้น ไม่ย้อนหลัง)

### เช็กอิน

ห้องบางห้องกำหนดให้ต้องเช็กอิน **ถ้าไม่เช็กอินภายในเวลาที่กำหนด ระบบจะปล่อยห้องคืน
ให้คนอื่นจองได้** และคุณจะได้รับแจ้งเตือน

- เช็กอินได้ตั้งแต่ **15 นาทีก่อนเริ่ม** จนถึงหมดเวลาผ่อนผัน (ปกติ 15 นาทีหลังเริ่ม)
- กดปุ่ม **เช็กอิน** ในรายละเอียดการจอง

### คิวรอห้องว่าง

ถ้าห้องที่ต้องการถูกจองแล้วและห้องนั้นเปิดใช้คิวรอ ให้กด **เข้าคิวรอห้องว่าง**
เมื่อมีคนยกเลิก ระบบจะแจ้งคุณตามลำดับคิว พร้อมเวลาที่ต้องยืนยันภายใน (ปกติ 30 นาที)

## 7. ตั้งค่าการแจ้งเตือน

เมนูโปรไฟล์ → **การแจ้งเตือน**

เลือกช่องทางที่ต้องการ (อีเมล / LINE / ในระบบ) และเลือกเวลาเตือนก่อนประชุม
(24 ชั่วโมง / 2 ชั่วโมง / 1 ชั่วโมง / 15 นาที / 5 นาที — เลือกได้หลายอย่าง)

### เชื่อมบัญชี LINE

1. เพิ่มบัญชีทางการของระบบเป็นเพื่อนใน LINE (ขอ QR code จากผู้ดูแลระบบ)
2. ไปที่โปรไฟล์ → การแจ้งเตือน → **ขอรหัสเชื่อมบัญชี**
3. ระบบให้รหัส 8 ตัว **ใช้ครั้งเดียว หมดอายุใน 15 นาที**
4. พิมพ์รหัสนั้นในแชตบัญชีทางการ
5. ระบบตอบว่าเชื่อมสำเร็จ และเปิดการแจ้งเตือนทาง LINE ให้อัตโนมัติ

**เลิกรับแจ้งเตือน LINE:** กด "ยกเลิกการเชื่อม LINE" ในหน้าโปรไฟล์
หรือบล็อกบัญชีทางการก็ได้ ระบบจะหยุดส่งให้เอง

### ศูนย์การแจ้งเตือน

ไอคอนกระดิ่งบนแถบบน — ตัวเลขสีส้มคือจำนวนที่ยังไม่อ่าน
กดเข้าไปดูทั้งหมด และกด "ทำเครื่องหมายว่าอ่านแล้วทั้งหมด" ได้

## 8. แก้ไขข้อมูลส่วนตัวและรหัสผ่าน

เมนูโปรไฟล์ → **โปรไฟล์**

- แก้ชื่อ แผนก ตำแหน่ง เบอร์โทร และภาษา
- แท็บ **รหัสผ่าน** เปลี่ยนรหัสผ่าน (ต้องใส่รหัสผ่านปัจจุบัน)
- **ออกจากระบบทุกอุปกรณ์** — ใช้เมื่อสงสัยว่ามีคนอื่นเข้าถึงบัญชีของคุณ

> อีเมลเปลี่ยนเองไม่ได้ ต้องติดต่อผู้ดูแลระบบ

---

## 9. ใช้งานบนมือถือ

ระบบใช้งานบนมือถือได้เต็มรูปแบบ ไม่ต้องติดตั้งแอป

- มุมมองรายวันเป็นค่าเริ่มต้น อ่านง่ายที่สุดบนจอเล็ก
- แถบล่างมีเมนูหลัก (ปฏิทิน / การจองของฉัน / รออนุมัติ)
- ตัวกรองเปิดเป็นแผ่นเลื่อนขึ้นจากด้านล่าง
- ปุ่มทุกปุ่มมีขนาดพอให้แตะได้สะดวก

**เคล็ดลับ:** เพิ่มเว็บไปที่หน้าจอโฮม (Add to Home Screen) จะเปิดได้เร็วเหมือนแอป

## 10. ถามบ่อย

**ทำไมการจองของฉันขึ้นว่า "รออนุมัติ"**
ห้องนั้นกำหนดให้ต้องได้รับอนุมัติก่อน ระบบแจ้งผู้อนุมัติแล้วและจะแจ้งผลกลับให้คุณ

**คนอื่นเห็นหัวข้อประชุมของฉันไหม**
ขึ้นกับที่คุณเลือกในช่อง "ความเป็นส่วนตัว" (ดูข้อ 3)

**จองล่วงหน้าได้นานแค่ไหน**
ขึ้นกับการตั้งค่าของแต่ละห้อง ปกติ 90 วัน ถ้าเกินระบบจะบอกจำนวนวันที่อนุญาต

**ทำไมช่องเวลาบางช่องกดไม่ได้ แม้ดูเหมือนว่าง**
บางห้องมีเวลาเตรียมห้องก่อน/หลังประชุม (buffer) ช่วงนั้นจึงถูกกันไว้
หรืออยู่ในช่วงปิดปรับปรุง

**ไม่ได้รับอีเมลแจ้งเตือน**
ตรวจกล่อง Junk/Spam ก่อน แล้วตรวจว่าเปิดการแจ้งเตือนทางอีเมลไว้ในหน้าโปรไฟล์
ถ้ายังไม่ได้ ให้แจ้งผู้ดูแลระบบ (เขาดูสถานะการส่งย้อนหลังได้)

**เข้าสู่ระบบไม่ได้**
ตรวจว่าใช้อีเมลองค์กรถูกต้อง ถ้าใส่รหัสผิดหลายครั้งระบบจะล็อกชั่วคราว
รอ 15 นาทีหรือใช้ "ลืมรหัสผ่าน" ถ้ายังไม่ได้ให้ติดต่อผู้ดูแลระบบ

**แจ้งปัญหาให้ผู้ดูแลระบบอย่างไรให้แก้ได้เร็ว**
บอกสามอย่าง: ทำอะไรอยู่ / เวลาที่เกิดปัญหา / ข้อความที่เห็นบนหน้าจอ
